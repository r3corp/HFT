## 🔒 Security Guidelines

### Data Protection
- **Never commit**: API keys, passwords, tokens, credentials
- **Use environment variables**: For sensitive configuration
- **Encrypt sensitive data**: At rest and in transit
- **Audit regularly**: Review access and permissions

### Tool Permissions
| Access Level | Tools | Risk | Use Cases |
|-------------|-------|------|-----------|
| Read-only | Read, Grep, Glob | Low | Analysis, audits, reviews |
| Write | + Write, Edit | Medium | Development, documentation |
| Execute | + Bash | High | Automation, deployment |
